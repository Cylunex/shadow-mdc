# Shadow MDC

本地优先的影片元数据识别、刮削与整理服务。主要覆盖 JAV，同时支持国产长尾、欧美场景、无稳定编号和用户指定 URL 的内容。

## 设计重点

- **作品与文件分层**：作品保存标题、演职员、剧情、图片和来源；文件独立保存画质、编码、音轨、时长与指纹。
- **多身份识别**：结合番号、标题、来源 URL、provider ID 和 oshash；确定性身份可自动匹配，低置信候选留待确认。
- **本地线索与增量扫描**：支持实体视频、STRM、映射盘和 UNC；复用未变化文件的技术信息，垃圾过滤不删除源文件。
- **多源聚合与追溯**：按内容类型路由来源，保存字段来源和快照；手动字段锁保护用户编辑，来源失败相互隔离。
- **本地元数据互操作**：读取 NFO、影片同名 sidecar 和相邻图片；导出 Kodi/Emby 可用的 NFO 与封面。
- **演员与分类管理**：维护演员、别名、头像、关联作品及目录人物规则，辅助非标准文件识别。
- **可审计整理**：原地、复制、移动、硬链接和软链接五种模式，先生成计划，执行后保留运行记录与可用的撤销日志。
- **图片与中文展示**：集中保存作品图片和缩略图，复用缓存；中文标题与简介翻译独立于原始来源数据。
- **任务与可选连接器**：查看进度、取消标记和中断恢复；可选接入字幕、115/OpenList、STRM、Emby 与配置化播放来源。
- **刷流浏览**：在同一应用内浏览片库或配置的外站来源，支持播放器自动换源及任务入库入口。

## 开发入口

使用 Python 3.12+、uv、Node.js、pnpm 和 just：

```bash
just setup
just dev
```

本地 API 和 Web 开发地址由启动命令输出。验证入口：

```bash
just test
just check
just build
```

`just test` 包含 Python 测试与前端离线回归；`just check` 还包含 Python lint、类型检查及前端类型检查。
实际运行配置、站点列表和凭据保存在本地忽略路径或独立运维目录；仓库仅保留脱敏示例。
