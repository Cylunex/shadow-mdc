# 多维分类与数据迁移

分类按维度组织，每个分类项都有永久 ID、展示名称、搜索别名和修订号。它与作品通过正式关联表连接；
修改名称不改变作品关联、筛选和动态片单。主题标签继续保留来源词，作为更细的内容特征入口。

| 维度 | 用途 | 示例 |
| --- | --- | --- |
| 内容分区 `contents` | 内容所属分区 | JAV、国产原创、欧美内容、动画内容 |
| 作品类型 `types` | 作品大类 | 电影、剧集、动画、纪录片、综艺 |
| 表现形式 `forms` | 呈现形式，可多选 | 合集、自拍、VR |
| 语言 `languages` | 作品原始对白语言，可多选 | 中文、粤语、日语、英语、无对白 |
| 制作地区 `regions` | 明确的制作国家或地区 | 日本、中国大陆、美国 |

题材统一由标签树管理，分组是高层标签节点；选中节点包含整棵子树，统计按作品去重。年代由发行年派生，时长由作品的 `runtime_seconds` 派生。
演员、机构、系列、播放状态与主题标签仍可组合筛选。作品类型放在「更多筛选」。
同一维度的多项选择采用“任一匹配”，不同维度采用“同时匹配”。

没有明确分类的维度显示“待补”，可以直接筛选。内容分区在没有人工指定时由作品的来源体系 `family` 派生；
人工指定优先，清空后恢复派生。来源分区 `Work.category` 继续用于既有识别和文件库路由，不能等同制作地区。
“想看”偏好与媒体可用性也分别筛选，可组合为“想看且有关联文件”；枚举与状态边界见[类型审查](type-enum-audit.md)。
语言、类型和制作地区不会从标题、来源体系或分区猜测。作品语言不表示某一片源的配音或字幕。
同一作品的配音、字幕语言属于片源版本，不能把中文字幕合并成作品中文语言。

## 数据模型与操作

- `catalog_classification_terms` 保存分类项：ID、维度、名称、归一化名称、别名和修订号。
- `work_classifications` 保存作品与分类项的关联，主键防止重复关联，按分类项建立反查索引。
- `work_taxonomy` 只保存人工发行年，分类不再保存为该表的字符串数组。
- 可选初始展示信息与词条在外部 `<reference_data_dir>/classifications.seed.json`，只填充缺少的分类项；已修改的名称和别名不会被覆盖。未提供时仅生成结构所需的待补项和来源体系投影，见[运行数据边界](data-storage.md)。
- 原「分类」页面保留为主题标签图卡：展示标签封面、名称和作品数，支持搜索、排序与分页，点击后按标签筛选作品。
- 内容分区、作品类型、语言等维度在作品列表中组合筛选，在作品详情中查看和编辑；分类项的新增与改名放在作品库的「片单与资料工具 → 分类字典」。
- 作品列表的组合筛选、作品详情与编辑表单共用这些分类项。选择、链接与片单存储 ID，界面显示名称。
- 分类项改名使用修订号检测并发修改；同维度名称与别名不允许歧义。新增自定义项的 ID 与名称无关。

## 一次性迁移

数据库初始化时，在同一事务中把旧 `work_taxonomy.genres/forms/regions` 数组迁入分类关联表。
已知名称与别名归并到预置 ID；未知名称创建正式自定义项，保留原展示名称，重复大小写写法归并。
迁移同时把服务端动态片单中的旧分类条件转换为 ID，保留其它条件和人工发行年。
浏览器本机保存的分类筛选在首次加载时一次性转换为 ID；未知分类项先正式创建，迁移成功后更新本机保存结果。
逐项核对迁入的作品关联后删除旧列；数据格式错误或引用缺失时回滚，不删除来源列。
迁移可重复执行，数据库继续使用同一作品 ID；运行时接口不再接受旧分类名称作为筛选值，也不保留旧列双写。

迁移随服务启动执行，发布前按运维约定备份并验证数据库。代码测试使用隔离数据库，不直接修改运行中的片库。
旧 URL 中的分类名称不作兼容，新的链接和筛选使用正式 ID。

## 分类精简迁移与时长

服务启动先完成旧数组迁移，再将题材词条按名称和别名合入持久标签字典，并把作品关联迁入 `Work.tags`。
已有标签 ID、展示名、显隐、分组和来源标记保留；新增词条归入「题材」组。
主名已匹配的词条优先沿用该身份；主名未匹配且多个别名各自指向不同标签时，保留为独立标签。
冲突别名留在历史分类映射，不覆盖既有词条；别名不会使服务启动中止。词典写入先于数据库关联改写，
失败可以重试；数据库回滚最多留下未使用的词条，不会丢失作品关联。核对标签写入后移除旧题材关联，
原分类词条保留 `tag_id` 映射。后续启动不会恢复用户后来移除的标签，原有字段锁继续保留，迁入的明确题材按人工标签编辑锁定，避免覆盖式重刮丢失。

字幕分类记录及关联保留为历史资料，不出现在作品分类读取或编辑中，也不并入作品语言。
旧 `forms:feature` / `forms:short` 词条和关联保留，但退出新分类菜单；新作品不再靠人工长短片分类。
旧动态片单和链接中的题材条件改查统一标签，同维度 OR、跨条件 AND 的含义保持；
旧字幕及长短片条件仍按历史记录匹配，不静默丢弃。`legacy_terms` 仅用于旧本机筛选名称迁移。

时长筛选接受 `duration_min`（秒，含边界）、`duration_max`（秒，不含边界）以及 `unknown_duration`。
预置区间为小于 30 分钟、30 至 60 分钟、60 至 120 分钟、120 分钟及以上和时长待补。
未填写、零及负值时长都属于待补，不能命中任一已知时长区间。不根据单个文件、分片或合集文件时长推断作品时长。
统计时保留其它条件，清除时长条件后计算各区间数量；Web、移动目录、动态片单和 skill 查询共用同一规则。

## 接口

- `GET /api/catalog/classifications`：维度、全部分类项、名称、别名、修订号和作品计数。
- `POST /api/catalog/classifications/terms`：新增分类项。
- `PUT /api/catalog/classifications/terms/{id}`：修改展示名称与别名，携带当前修订号。
- `GET/PUT /api/catalog/works/{id}/taxonomy`：读取或编辑作品分类；数组只接受本维度的正式 ID。
- `POST /api/catalog/works/query` 和 `/facets`：组合筛选及分类统计。
- 移动端 `/api/media/v1/catalog` 提供同样的分类读取与筛选，沿用移动访问令牌，不开放编辑。

回归测试覆盖旧列迁移与删除、错误回滚、重复初始化、动态片单迁移、跨维度组合与多选、待补筛选、
名称修改、并发修订冲突、移动读取及页面交互。
