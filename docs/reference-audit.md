# 参考项目功能审计

本审计基于本地参考仓库中的 JavSP、JavSP-Web、MDCX、MDC-NG 与 Amane。
Shadow MDC 只吸收行为、边界和使用流程，所有代码、模型、接口与测试均独立实现。

## 项目观察

| 项目 | 值得吸收 | 需要避免 |
|---|---|---|
| JavSP | 多站并发、按内容类型路由、字段汇总、分片、封面与 NFO、可配置命名 | 同步 CLI 流程、站点逻辑与文件操作耦合、失败后人工流程不足 |
| JavSP-Web | 持久任务、阶段进度、预设、定时刮削、Cookie 同步、下载器和媒体服务器联动 | 把配置文件直接当业务模型、默认账号和高权限集成混在主流程 |
| MDCX | 来源覆盖广、国产/FC2/素人分流、字幕、演员、图片标签、软链接 | 大量站点特例堆叠、设置项过密、旧架构技术债 |
| MDC-NG | 原地/复制/移动/硬链/软链五模式、监控兼容模式、任务详情 | 本机副本只有 README 与静态资源，无法把宣传项当作已验证实现细节 |
| Amane | 数据库真值、多源字段来源、资源物化、任务图、HTTP 缓存/限流、插件边界 | 直接复制其源码或模型；过早引入 AI 助理和复杂插件运行时 |

## Shadow MDC 对照

| 能力 | 状态 | Shadow MDC 方案 |
|---|---|---|
| 文件名、目录与无番号线索 | 已实现 | 文件名优先、三级目录回退、用户别名；在线未命中后接受本地优化记录 |
| `.strm`、映射盘、UNC | 已有 | STRM 只读取并脱敏 locator，网络路径局部失败不终止整库 |
| 番号直接建档 | 已实现 | 无需本地文件，按番号查询并创建/更新 Work |
| 媒体库批量识别 | 已实现 | 番号精确命中才关联、失败待确认；无番号标题搜索失败后本地优化 |
| 多来源逐字段聚合 | 已实现 | 主结果定标量，精确同番号来源补空字段并合并演员、标签和图片 |
| 字段来源与原始快照 | 已实现 | `field_sources` 记录标量来源，`SourceSnapshot` 保留来源记录 |
| 五种整理模式 | 已实现 | 原地 NFO、复制、移动、硬链接、软链接；全部先计划再确认 |
| 分片与字幕 | 已实现 | CD/PART/V/A-B/尾部单数字；字幕同分片配对并随媒体处理 |
| 在线图片本地缓存 | 已实现 | URL 哈希去重、MIME/大小校验、私网拦截、整理时复制缓存封面 |
| 大库增量扫描 | 已实现 | 文件大小和修改时间未变时复用时长与 oshash |
| 垃圾目录与常见容器 | 已实现 | 回收站/元数据目录跳过，扩展 ISO/M2TS/VOB/RMVB 等容器 |
| 来源诊断、代理与重试 | 已有 | 区分未配置、无结果、超时、拦截和成功，代理只在服务端配置 |
| 持久运行历史 | 已实现 | 扫描、番号查询、图片和整理记录范围、状态、统计与完成时间 |
| 后台任务、阶段进度与取消 | 计划 | 可取消的网络阶段与不可中断文件阶段分开，运行历史模型继续扩展为 Worker |
| 目录监控与定时任务 | 计划 | 本地事件模式 + NAS 轮询模式，先登记/自动刮削分级，不自动整理 |
| 更多来源与内容路由 | 已扩展 | 普通 JAV 接入 R18.dev、FANZA、JavLibrary、MGStage、JavDB、JavBus、Jav321、AirAV、AVSOX、FreeJavBT；FC2 额外使用 FC2Club/FC2Hub/FC2 Contents Market/Paipancon。每源均有离线 fixture、合法未命中、非法输入和解析漂移测试 |
| 本地演员作品库 | 已实现 | 汇总演员、别名、分类和关联作品，已知演员反向辅助下一轮路径识别 |
| 演员资料与头像 | 已实现 | 非 JAV 名单可编辑名称、别名、分组、简介、备注并上传本地头像；媒体服务器同步待后续扩展 |
| 标题翻译 | 已实现 | 日/英/韩到简中、自动与批量补翻译、独立缓存；原文和来源快照不被覆盖 |
| 插件系统 | 后期 | 先稳定 Provider 契约，再做受信任本地插件；不在主进程加载未知代码 |
| 下载器、磁力、在线播放 | 不纳入核心 | 保持元数据与用户已有媒体边界；外部自动化以后只做显式可选连接器 |

## 实施顺序

1. 先保证识别、聚合、图片、NFO 和文件整理闭环可靠。
2. 再把长操作迁入持久任务，增加进度、重试、取消和运行历史。
3. 增加监控/定时、媒体服务器刷新与人物资料。
4. Provider 契约稳定后扩展来源和插件，不以“来源数量”代替可测试性。
